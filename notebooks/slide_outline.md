### สไลด์ 5 ○ — ก่อนใช้ mask: ยืนยันก่อนว่าเลขปล้องตรงจริง
mask เก็บค่าเป็นเลข 1–15 แต่ **ไม่มีเอกสารบอกว่า 1 คือ T3 จริงไหม** — ถ้าเดาผิดทั้งงานพัง จึงพิสูจน์ด้วยหลักฐาน 3 ทางที่ไม่พึ่งกัน:

1. label 15 อยู่ใน **832 จาก 833 ภาพ** และเป็นปล้องล่างสุดเสมอ → เป็น anchor ที่ L5
2. มี **9 ภาพที่ label ข้ามเลข** (เช่น 1..8, 10..15) → เลขเป็น**ตำแหน่งกายวิภาคตายตัว** ไม่ใช่การนับเรียง
3. **offset test** — เลื่อน mapping ±1, ±2 ปล้อง แล้ววัด Jaccard กับปล้องที่แพทย์ประเมินได้

| offset | −2 | −1 | **0** | +1 | +2 |
|---|---|---|---|---|---|
| Jaccard | 0.819 | 0.896 | **0.986** | 0.921 | 0.851 |

**offset 0 ชนะขาด (median 1.000) → mapping ถูกต้อง**

**รูป**: กราฟแท่ง 5 แท่งของ offset test · แท่งกลางสูงเด่น
*(สไลด์นี้ทำหน้าที่บอกว่างานนี้ไม่เดาอะไรเลย — ถ้าเวลาน้อยพูดปากเปล่า 20 วินาทีก็พอ)*

### สไลด์ 8 ◆ — ข้อจำกัดที่ต้องพูดก่อนใครถาม: อคติจากการเลือกตัวอย่าง
**ภาพ 833 ภาพที่มี mask ไม่ใช่ตัวอย่างสุ่มจาก 2,900 ภาพ**

| | มี mask (833) | ไม่มี mask (2,067) |
|---|---|---|
| ผู้ป่วยที่มีกระดูกหัก ≥ 1 ปล้อง | **71.1%** | **19.7%** |
| อายุเฉลี่ย | 71.6 | 71.1 (p = 0.23) |

Mann–Whitney U: **p = 9 × 10⁻¹³³** — อายุไม่ต่างกันเลย แต่สัดส่วนการหักต่างกันกว่า **3 เท่า**
⇒ mask ถูกวาดโดยเลือกจากเคสที่มีกระดูกหักเป็นหลัก

**ตีความให้ถูก**
- ❌ **ห้ามรายงานอัตราข้างต้นเป็นค่าความชุก (prevalence)** — สูงกว่าประชากรจริงราว 3 เท่า
- ✅ **รูปแบบเชิงตำแหน่งยังเชื่อถือได้** เพราะกลุ่มที่ไม่มี mask ก็กระจุกที่ T11/T12/L1 เช่นกัน (4.95% / 8.07% / 8.77%) เพียงระดับต่ำกว่า
- ตัวเลข performance ทุกตัวในเด็คนี้เป็น performance **บนชุดที่เอนเอียงไปทางเคสที่หัก** ไม่ใช่ในประชากรจริง

**รูป** *(ต้องสร้าง)*: กราฟแท่งคู่ 71.1% vs 19.7% ขนาดใหญ่กลางสไลด์ + ข้อความ "ห้ามรายงานเป็น prevalence" เป็นแถบเตือน
*(สไลด์นี้สร้างความน่าเชื่อถือทั้งเด็ค — เราพูดข้อจำกัดเองก่อนถูกถาม)*

### สไลด์ 10 ▽ — คำถามค้างเรื่องคอลัมน์ `vq`
คอลัมน์ `vq` กรอกครบถึง **99%** (ค่า 0–5 และ 99) แต่ตรวจแล้ว **ไม่ใช่ตัววัดความรุนแรงของกระดูกหัก**:

| การตรวจสอบ | ผล |
|---|---|
| Spearman(`vq`, จำนวนปล้องที่หัก) | เพียง **+0.25** |
| `vq` ตรงกับจำนวนปล้องที่หักเป๊ะ | เพียง **12.7%** |
| คนที่ `vq = 2` (กลุ่มใหญ่สุด) | **891 คนไม่หักเลยสักปล้อง** |

→ อาจเป็นข้อมูลที่มีค่ามาก แต่**เราไม่ทราบความหมาย จึงยังใช้ไม่ได้**

### สไลด์ 11 ◆ — สมมติฐานที่ 1: ป้อนภาพทั้งใบ ทาย 15 ปล้องพร้อมกัน
**ออกแบบ**: EfficientNet-B0 (pretrained) → 15 Linear heads (1 หัวต่อ 1 ปล้อง) → grade 0–3
**Loss**: Focal Loss (γ=2, α=[0.1,1,1,1]) และ **mask ปล้องที่แพทย์ประเมินไม่ได้ออกจากทั้ง loss และ metric**
**Split**: 70/15/15 = 2,030 / 435 / 435 แบบ multilabel stratified (เลือก best seed จาก 600 ครั้ง)
**ภาพ**: `PNG_proc/` = Wavelet Denoise → Guided Filter → CLAHE

**รูป**: แผนภาพสถาปัตยกรรม (ภาพเต็ม → backbone → 15 หัว) + `dl-sp/runs/_preprocess_demo.png` แสดงผลของ preprocessing

### สไลด์ 13 ○ — บทเรียนเชิงระเบียบวิธีจาก v07: val เลือกโมเดลไม่ได้
ทดลองเปรียบเทียบเกณฑ์เลือกโมเดล (val Macro-F1 vs val loss) แล้วพบว่า:

> **corr(val Macro-F1, test Macro-F1) = +0.009**

**จุดพีคของ val เส้นเดียว แทบเป็นการสุ่ม** → ทุกงานหลังจากนี้เปลี่ยนไปใช้ **k-fold CV** แทน validation set เดี่ยว
*(นี่คือเหตุผลที่บทที่ 4 ใช้ 5-fold และเป็นตัวเลขที่ควรอ้างเวลาถูกถามว่าทำไมไม่ใช้ val ธรรมดา)*

### สไลด์ 14 ◆ — สมมติฐานที่ 2: เปลี่ยนหัวโมเดลเป็น Transformer 15 vertebra-query
**ที่มา**: อาจารย์ขอ "Transformer 15 attention head" — เราตีความเป็น **15 query token (1 ต่อ 1 ปล้อง)** ที่ cross-attend ไปยัง feature map ของ EfficientNet-B0 แบบ DETR

```
ภาพ 224×224 → EfficientNet-B0 → feature map (1280,7,7)
              → 1×1 conv → 49 tokens + positional embedding
15 query (T3…L5) → Transformer decoder ×3 (self-attn + cross-attn + FFN)
              → shared Linear(256→4) → logits (B,15,4)
```
6.73M พารามิเตอร์ · discriminative LR (backbone 1e-4 / decoder 3e-4)

**ผล**: val 0.3185 / **TEST 0.2899** = เทียบเท่า baseline (v04 0.3030, v06 0.2916) — **อยู่ในแถบ plateau เดียวกัน**

**⭐ แต่ได้ของแถมที่มีค่ากว่าตัวเลข**: query ทั้ง 15 ตัว **เรียนรู้ที่จะโฟกัสคนละบริเวณของภาพ เรียงจาก T3 บนลง L5 ล่างอย่างเป็นระเบียบ ทั้งที่ไม่เคยได้รับ label ตำแหน่งใดๆ เลย** (ข้อมูลที่ให้มีแต่ grade ต่อปล้อง ไม่มี bounding box)

- query ของ **T11 / T12 / L1 โฟกัสแน่นและคมที่สุด** → ตรงกับโซนที่หักบ่อยและได้ F1 สูงสุด (T11 .337 / T12 .387 / L1 .408)
- ⇒ โมเดลเรียนรู้กายวิภาคของกระดูกสันหลังโดยปริยาย และใช้ต่อเป็น **weak localization** ได้ฟรี

เสริม: `dl-sp/attention_sample_2855.png` overlay บนภาพจริง

### สไลด์ 16 ◆ — เราเคยได้ "4 กลุ่ม" แล้วพบว่าเป็นของปลอม *จุดแข็งเชิงระเบียบวิธี*
**รอบแรก** เราใช้ silhouette sweep เลือก `eps` โดย**บังคับให้ได้ 2–8 กลุ่ม** → ได้ "4 clusters" ที่ดูแยกกันชัดเจนบนภาพ UMAP และบังเอิญตรงกับจำนวน grade พอดี

**สิ่งที่ทำให้สงสัย**: ความรุนแรงของกระดูกหักเป็น**ค่าต่อเนื่อง** ไม่ควรสร้าง "ช่องว่างคม" ระหว่างกลุ่มได้ และกลุ่มที่มีอัตราหักสูงสุดก็ยังมีคนปกติถึง 56.8%

**การทดสอบ**: ฉาย embedding 768 มิติ ลงบนแกนที่แยกสองกลุ่มนั้น แล้วดูรูปทรงการกระจายรวม

| การทดสอบ | ผล | ความหมาย |
|---|---|---|
| **Bimodality Coefficient** | **0.448** (เกณฑ์ bimodal > 0.555) | **UNIMODAL — ไม่มีหุบเขา ไม่มีช่องว่าง** |
| PCA (linear space จริง) | ก้อนเดียวต่อเนื่อง | ไม่มีรอยแยก |
| DBSCAN บน PCA-50 | 0 cluster ทุก eps | ไม่มีโครงสร้างกลุ่ม |

**✅ ข้อสรุป: "4 clusters" เป็น artifact ของ UMAP** — UMAP ฉีก manifold ต่อเนื่องออกเป็นกลีบ แล้ว DBSCAN ติดป้ายกลีบเหล่านั้นเป็นกลุ่ม (เป็นข้อจำกัดที่รู้กันดีของ UMAP/t-SNE)

**เราลบผลและรูปทั้งหมดที่สร้างบนกลุ่มปลอมนั้นทิ้ง** และเปลี่ยนมาใช้ k-distance knee แทน

### สไลด์ 18 ◆◆ — คำตอบ: รอยหักเป็นสัญญาณเฉพาะที่ ภาพทั้งใบจึงมองไม่เห็น
**ดูรูปจริงที่จัดกลุ่มตาม Genant grade ของแพทย์:**

> **ภาพของ grade 0 → 1 → 2 → 3 หน้าตา *แทบแยกไม่ออก* ในระดับภาพทั้งใบ**

**หลักฐานประกอบกัน 4 ชิ้น**

| หลักฐาน | ตัวเลข |
|---|---|
| คนไข้ที่หัก ส่วนใหญ่หักแค่ 1–2 ปล้อง | **798 / 1,000 = 80%** (สไลด์ 4) |

**⇒ โมเดลที่ดูภาพทั้งใบมี “เพดานเชิงโครงสร้าง” (structural ceiling)**
รอยหัก grade 1–2 คือการเปลี่ยนความสูงของกระดูก**เพียงปล้องเดียว 20–40%** ซึ่งเล็กมากเมื่อเทียบกับภาพทั้งใบ — การ pool ทั้งภาพเป็นเวกเตอร์เดียวย่อมกลืนสัญญาณนี้หายไป

**⇒ ปัญหาไม่ได้อยู่ที่ "จูนไม่เก่งพอ" แต่อยู่ที่ระดับของสัญญาณ (local vs global)**
**⇒ ทางแก้เชิงโครงสร้าง: crop ทีละปล้องก่อนแล้วค่อยจำแนก (two-stage)** — ทำให้รอยหักกลายเป็นสัญญาณ *global* ของภาพครอป

### สไลด์ 22 ◆◆ — คำถามที่ 3: สัญญาณคือ "รูปทรง" หรือ "เนื้อภาพ" *ข้อค้นพบสำคัญที่สุดของบทนี้*
**การทดลอง**: เทียบ crop X-ray จริง กับ **เงา mask ล้วน (silhouette)** ที่เป็นภาพขาว-ดำ **ไม่มีเนื้อภาพ X-ray เลยแม้แต่พิกเซลเดียว**

| contrast | dAUC | 95% CI | |

**⇒ เนื้อภาพ X-ray ไม่ได้ถูกใช้เลย สัญญาณทั้งหมดคือรูปทรงเส้นขอบของ mask**

**สมเหตุสมผลทางคลินิก** — Genant นิยามด้วย**อัตราส่วนความสูง** เงารูปลิ่ม (wedge) จึงเพียงพอ

> 1. **mask วาดโดยมนุษย์** — ทำนายเกรดจากเงา = ถอดการวัดของแพทย์กลับจากเส้นที่แพทย์วาด **ใกล้ circular reasoning** ไม่ใช่การ "ตรวจจับจากภาพ"
> 2. **ตอน deploy ไม่มี mask** — ต้องมี auto-segmentation ก่อน แล้ว error จะสะสมต่อ ⇒ ตัวเลข 0.94 เป็น **"เพดานบนแบบ oracle"** ไม่ใช่ performance จริง
> 3. ตัวเลขทั้งหมดอยู่บน crop set ที่ bias (สไลด์ 8)

### สไลด์ 36 ◆ — รอบที่ 1: ยืนยัน masked > bbox แล้วเจอปัญหาจาก Grad-CAM
**ผลตรงกับ linear probe ในสไลด์ 21**: macro F1 0.428 → **0.547** (+11.9 pp) · AUC 0.797 → 0.861
**แต่ mild แย่ลง** 0.261 → 0.196 ขณะที่ severe ดีขึ้นมาก 0.457 → 0.714

**ตรวจด้วย Grad-CAM แล้วเจอสิ่งที่ไม่คาด**
- โมเดล **bbox**: สีร้อนอยู่**บนเนื้อกระดูก** 9 จาก 12 ภาพ
- โมเดล **masked**: หลายเคสสีร้อนอยู่ใน**มุมภาพที่เป็นพื้นดำล้วน ไกลจากกระดูก** — แม้ในเคสที่ทายถูก

**ต้องให้ความเป็นธรรม**: บางภาพสีร้อนเป็นแถบตั้งที่**ขอบซ้าย-ขวาของกระดูก** ซึ่ง**อาจไม่ใช่ข้อผิดพลาด** เพราะ Genant วัดสัดส่วนความสูงที่ขอบหน้า-กลาง-หลัง จุดที่ต้องวัดคือขอบพอดี

⇒ **ข้อได้เปรียบเชิงตัวเลขของ masked ยังอธิบายด้วย "โมเดลเข้าใจกระดูกดีขึ้น" ไม่ได้เต็มปาก**

**รูป** ✅ *รันใหม่แล้ว — ได้ 4 โมเดล*

**แต่ยังเหลือเคสที่สีร้อนกองอยู่มุมดำ** โดยเฉพาะบางเคสที่ทายถูก — **ปัญหายังไม่หายไปทั้งหมด**

> ⚠️ **สิ่งที่ยังทำไม่ได้**: การเทียบ **bbox vs masked** ด้วย Grad-CAM ทำไม่ได้ตอนนี้

> ในเด็คจึงควรเล่าผล bbox จากตัวเลขในรอบที่ 1 และใช้ Grad-CAM ชุดใหม่นี้พูดเรื่อง "มุมดำ" อย่างเดียว

**ผลกวาด preprocess 10 แบบ** — `flatten` ชนะ 0.647 ± 0.010 นำที่ 2 อยู่ 2.5 pp
**และทุกตัวที่ขึ้นต้นด้วย `destripe_` อยู่ครึ่งล่างหมด** ← **ขัดกับสมมติฐานหลักของรอบที่ 2** ที่ว่า "ลบลายเส้นก่อนแล้วต่อยอดได้"
(`destripe` ยังชนะ AUC ที่ 0.937 แต่ไม่ใช่ฐานที่ควรต่อยอด) · `none` อยู่อันดับ 7 จาก 10

**ผลกวาด augment 8 แบบ** — รอบที่ 2 เคยประกาศ **ห้าม** flip / scale / elastic ด้วยเหตุผลเชิงทฤษฎี (บิดรูปทรง = บิด label)
**รอบนี้ทดสอบข้อห้ามแทนที่จะเชื่อ** → **ทุกชุดที่มี shape อยู่ครึ่งบน และ `shape` ล้วนๆ ชนะทุกชุดที่ปฏิบัติตามข้อห้าม ยกเว้น `strong`**

*เหตุผลที่ทฤษฎีเดิมผิด*: ข้อห้ามตั้งอยู่บนสมมติฐานว่าโมเดลกำลังเรียนรูปทรงที่แม่นยำอยู่แล้ว แต่หลักฐานชี้ว่า**ยังไม่ถึงขั้นนั้น** — ปัญหาหลักคือ overfit **ประโยชน์ในฐานะ regularizer จึงมากกว่าความเสียหายต่อ label**

- `intensity` (ชุดที่เคยวางว่า "ปลอดภัยที่สุด") **แพ้ `none` ทั้ง 2 seed**
- **มีเพดาน**: เติม shape ให้ `standard` ช่วย +2.7 pp แต่เติมให้ `strong` กลับ −0.9 pp
- `strong` ชนะ macro F1 แต่ **`strong_shape` ชนะทุกตัวชี้วัดที่เกี่ยวกับการตรวจจับ** (mild 0.413 / moderate 0.598 / AUC 0.938)

**จุดที่ดีที่สุด (`flatten` + `strong`)**: macro F1 0.565 → **0.647** · mild 0.152 → **0.370** · moderate 0.333 → **0.500**

### สไลด์ 46 ◆◆ — 6 คำถาม *สไลด์ที่ต้องได้คำตอบกลับ*

83 รัน มัธยฐาน mild recall 0.304 · ทุกวิธีทางเทคนิคถูกลองหมดแล้ว

*ผู้อ่านภาพ 2 คนเห็นตรงกันแค่ไหนที่ grade 1 · มี borderline case ที่ label ได้ทั้ง 0 และ 1 ไหม*
→ ถ้า label เองมีความไม่แน่นอนสูง **เพดาน 0.30–0.50 ที่เราชนอาจไม่ใช่ความผิดของโมเดล**

**3. ปล้องข้างเคียง**
Genant ตัดสินโดย**เทียบกับปล้องข้างเคียง** แต่ masked crop ลบตัวอ้างอิงนั้นทิ้ง — และเราพิสูจน์แล้วว่ารูปทรงของปล้องเดี่ยวๆ แยก mild ไม่ได้
*ควรใส่ปล้องบน-ล่างเข้ามาในกรอบด้วยไหม · กี่ปล้อง · คุณหมอดูกี่ปล้องรอบๆ ตอนตัดสินจริง*

**4. จุดทำงานที่ยอมรับได้**
ตอนนี้: ปล่อยหลุด 31.5/132 (24%) · เตือนผิด 4.0% ของปล้องปกติ
*สำหรับการใช้คัดกรอง ควรดันไปทางไหน — ยอมเตือนผิดมากขึ้นเพื่อพลาดน้อยลงได้แค่ไหน*

**5. metadata ที่ควรมี**
*BMD / T-score · ประวัติกระดูกหักเดิม · การใช้ steroid — ตัวไหนที่คุณหมอใช้จริงตอนอ่านภาพ*

**6. คอลัมน์ `vq` คืออะไร**
กรอกครบ 99% แต่ไม่สัมพันธ์กับการหัก (ตรงเป๊ะแค่ 12.7% · คนที่ `vq=2` มี 891 คนไม่หักเลย)

### หลักการวาดให้ทั้งเด็คเป็นชุดเดียวกัน
- 1 สีเน้นสำหรับ "ตัวที่กำลังพูดถึง" ที่เหลือสีเทา — ห้ามใช้สีรุ้ง
- ใส่ error bar / CI ทุกครั้งที่มีหลาย seed หรือหลาย fold (เป็นประเด็นของสไลด์ 42 ด้วย)
- แกน recall / AUC ตรึงช่วงเดียวกันทุกรูป เพื่อให้เทียบข้ามสไลด์ได้ด้วยตา
- **เขียนจำนวนปล้องจริงกำกับ % เสมอ** (เช่น "0.630 = 29/46 ปล้อง") — คุณหมออ่านจำนวนเคสง่ายกว่าอ่านสัดส่วน
- ใช้คำว่า "ปล่อยหลุด / เตือนผิด" แทน "false negative / false positive" ตลอดทั้งเด็ค

## เคล็ดการเล่า

1. **เส้นเรื่องคือ grade 1** — ตัวเลขนี้เดินผ่านทั้งเด็ค: มองไม่เห็นเลยตอนภาพทั้งใบ → F1 0.30 ตอน crop → 0.217 → 0.543 → 0.630 → 0.511 (binary) ถ้าต้องตัดสไลด์ ให้เก็บสไลด์ที่ตัวเลขนี้ขยับ
2. **มี 2 สไลด์บานพับ อย่ารีบผ่าน** — สไลด์ 18 (ทำไมต้อง two-stage) และสไลด์ 22 (สัญญาณคือรูปทรง) ทั้งเด็คก่อนหน้าคือการปูทาง และทั้งเด็คหลังจากนั้นคือผลของมัน
3. **สไลด์ 16, 25, 41 คือจังหวะ "เราคิดผิดแล้วแก้เอง"** — 4 clusters ที่เป็นของปลอม · k ที่เป็นลูกบิด · ข้อห้าม flip/scale ที่ผิด — เป็นจุดแข็งของงาน ไม่ใช่จุดอ่อน อย่ากลบ
4. **สไลด์ 44 คือจุดที่ต้องช้าที่สุด** — เป็นข้อค้นพบที่คุณหมอมีมุมมองที่เราไม่มี และเปลี่ยนวิธีรายงานผลของทั้งเล่ม
5. **อย่าพูดคำว่า macro F1 ก่อนสไลด์ 40** — ใช้ "จับได้กี่ปล้องจากกี่ปล้อง" แทนตลอด
6. **พูดข้อจำกัดเองก่อนถูกถามเสมอ** — selection bias (สไลด์ 8) · เพดานบนแบบ oracle (สไลด์ 22) · การทำซ้ำได้ (สไลด์ 42) สามข้อนี้ถ้าคุณหมอถามขึ้นมาก่อนจะเสียน้ำหนัก
